# 차곡 — 입시 일정 노트

HTML, CSS, JavaScript로 만든 반응형 입시 플래너입니다. 별도 백엔드나 빌드 없이 GitHub Pages에서 실행할 수 있습니다.

## 페이지

- `index.html`: 입시 일정과 체크리스트의 추가·조회·수정·삭제. localStorage에 JSON으로 저장하며 백업 내보내기·불러오기를 지원합니다.
- `school.html`: 학교 이름·지역으로 나이스 학교정보 API를 검색하고, 선택한 학교의 월별 학사일정을 조회합니다. 조회한 일정을 나의 플래너에 저장할 수 있습니다.

## 실행

VS Code에서 프로젝트 폴더를 열고 Live Server 확장의 **Open with Live Server**로 `index.html`을 실행하세요. JSON을 fetch로 읽으므로 파일을 직접 더블클릭하는 대신 HTTP 서버를 이용해야 합니다.

## 나이스 인증키

키 없이도 실제 API를 호출하지만 샘플 최대 5건만 조회됩니다. 전체 조회에는 [나이스에서 발급한 본인 인증키](https://open.neis.go.kr/portal/guide/apiGuidePage.do)가 필요합니다. 학교 페이지의 ‘API 인증키 설정’에서 입력합니다. 키는 탭 메모리에서만 사용하며 코드·localStorage에 저장하지 않습니다. 새로고침하면 다시 입력해야 합니다.

## 기본 입시 일정과 플래너 세팅

`data/admissions.json`에는 공식 공지·2027학년도 모집요강과 대조한 수능일, 지스트 면접, 경북대 지역인재 학종 1단계 발표, 포스텍 1단계 발표 및 전형별 면접, 대성 더프리미엄, 지스트 1차 발표, 경북대 면접 일정 10건이 있습니다. 화면의 ‘내 입시 일정 · 출처 확인’에서 공식 자료로 이동할 수 있습니다. 면접은 개인별 지정 일시와 지원 전형을 확인해야 합니다.

기존 저장 데이터가 있어도 `2027-requested-v1` 묶음을 한 번만 추가하며 사용자의 다른 일정과 할 일은 보존합니다. 추가 일정은 각각의 버전으로 한 번만 반영합니다. 반영 후 수정·삭제한 일정은 새로고침해도 복원하지 않습니다. 첫 화면은 2026년 10월입니다. 관련 준비 체크리스트 6개도 한 번 추가하며, 사용자의 기존 할 일과 완료 상태는 유지합니다. 미수정 예시만 정리합니다. 기존 `[예시]` 일정은 공식 일정이 아닙니다.

수능 D-day는 달력 데이터와 별도로 2026-11-19를 기준으로 계산합니다. 전날·당일·지난날을 구분하며, 열린 탭은 날짜가 바뀌면 자동 갱신됩니다. ‘수능일 보기’는 해당 날짜로 이동합니다. 브라우저나 접속 주소가 바뀌면 localStorage 데이터는 공유되지 않습니다.

## 디자인

크림색 바탕과 직선 구분선을 사용하는 코넬 노트 구성입니다. 왼쪽은 체크리스트·일정, 오른쪽은 월간 달력, 아래는 다음 일정 요약입니다. 둥근 카드·기울임·테이프 장식을 제거했습니다. 본문은 12px이며 학교별 색상과 수능 강조를 유지합니다. 스타일은 `style.css` 한 곳에서 관리하며 색상 변수는 `planner-theme.css`에 있습니다.

## 확인한 항목

- PC 1440px 렌더링과 모바일 390px iframe 렌더링
- 모바일 390px에서 문서 가로 넘침 없음
- 일정·할 일 추가, 수정, 삭제
- 완료 체크와 새로고침 후 localStorage 유지
- JavaScript 구문 검사

GitHub Pages 배포는 아직 완료되지 않았습니다. 저장소의 Settings → Pages에서 배포할 브랜치와 루트 폴더를 지정해야 합니다.

## 가독성

본문, 날짜, 일정 표시, 버튼과 입력창은 PC·모바일 모두 12px입니다. 제목과 D-day 숫자는 더 크게 표시합니다. 예시 입력 문구·응원 문구·반복 안내는 제거했으며 모바일 달력은 글자 크기 유지를 위해 가로 스크롤을 지원합니다. 일정 이름은 줄바꿈해 표시합니다.

학교별로 GIST(파랑), 경북대(주황), POSTECH(보라), 대성(청록)을 사용합니다. 수능은 붉은 배너와 해당 날짜 강조로 구분합니다. 발표·면접·모고 표시는 색상과 별도로 표시합니다. 긴 메모는 펼쳐 읽으며 요약은 한 줄로 축소했습니다.

## 나이스 실제 연결 확인

학교 페이지는 대구 계성고등학교를 실제 나이스 학교정보 API에서 자동 검색하고 월별 학사일정을 조회합니다. 2026-10 조회에서 전체 22건 중 샘플 5건의 응답을 확인했습니다. 다른 학교는 검색 결과에서 선택할 수 있으며, 인증키를 입력하면 즉시 다시 조회합니다. 인증키는 메모리에서만 사용합니다.

색상은 연한 크림 바탕·흰 종이·짙은 회색 글자 중심으로 정리했습니다. 학교별 색은 가는 일정 구분선에 사용하며, 수능은 붉은 숫자와 해당 날짜 강조로 구분합니다.

## 첨부 이미지 기반 디자인

흰 종이 바탕, 얇은 먹색 달력 선, 세리프 제목, 줄노트 체크리스트와 JAN–DEC 월별 탭을 적용했습니다. PC에서는 달력 왼쪽·할 일 오른쪽, 모바일에서는 월별 탭과 달력을 먼저 표시합니다. 월 탭은 실제 월 이동과 선택 상태를 지원합니다. 본문 12px, 직선 모서리, 학교별 일정 색상과 수능 D-day 강조를 유지합니다.

파스텔 인덱스 탭은 월별 이동을 지원하며 Reminders 탭은 할 일 입력창으로 이동합니다. 별도의 브라우저 알림 권한 없이 동작합니다.

일정 목록은 기본으로 월과 관계없이 전체를 표시하고, ‘선택한 달’로 범위를 좁힐 수 있습니다. 달력은 10월로 시작합니다. ‘기본 입시 일정 다시 담기’는 빠진 기본 일정만 추가하며 기존 내용과 할 일은 보존합니다.

최근 가독성 조정: 본문·날짜·입력창·버튼은 14px, 일정 제목은 15px로 확대하고 고딕체와 짙은 글자색을 적용했습니다. 월별 인덱스 탭은 12px입니다.

달력과 전체 일정 목록의 GIST·경북대·POSTECH 일정 제목을 누르면 공식 입학처를 새 탭에서 엽니다. 날짜 빈 영역의 선택 동작과 수정·삭제 버튼은 별도로 유지합니다.

## 최근 구성

수능 D-day와 다음 일정을 나란히 위에 두고, 달력·할 일·전체 일정은 테이프로 붙인 메모지 형태로 배치했습니다. 수능 날짜 칸은 손으로 그린 붉은 별로 표시합니다. 선택한 월의 인덱스는 기존 색을 유지하고 다른 월은 옅게 표시합니다. 학교 일정 제목은 공식 입학처 새 탭 링크입니다.

검색용 제목·설명·구조화 데이터와 정적 `guide.html`을 추가했습니다. 배포 후 canonical·sitemap 설정은 `SEO.md`와 `scripts/configure-site.mjs`를 참고하세요. 검색 순위·AI 답변 인용은 보장하지 않습니다.
